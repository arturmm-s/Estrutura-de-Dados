# Estrutura de Dados II

Repositório destinado ao armazenamento e à organização de exercícios, atividades práticas, estudos e projetos desenvolvidos durante a disciplina de **Estrutura de Dados II**.

Este repositório tem como objetivo acompanhar minha evolução acadêmica ao longo da disciplina, reunindo implementações práticas dos conceitos estudados e soluções desenvolvidas para diferentes problemas relacionados à organização, manipulação e processamento de dados.

Através das atividades presentes neste repositório, busco aplicar conhecimentos teóricos na prática, aprimorando a lógica de programação, a capacidade de resolução de problemas e a compreensão sobre eficiência e desempenho de algoritmos.

---

## Objetivos

Durante o desenvolvimento das atividades, os principais objetivos são:

* Compreender e aplicar diferentes estruturas de dados;
* Desenvolver algoritmos para manipulação e processamento de informações;
* Aplicar técnicas e algoritmos de busca e ordenação;
* Analisar a eficiência e a complexidade computacional dos algoritmos;
* Desenvolver soluções utilizando diferentes estruturas de dados;
* Compreender o impacto da escolha de algoritmos no desempenho das aplicações;
* Aprimorar a lógica de programação e a capacidade de resolução de problemas;
* Desenvolver uma base sólida para a construção de soluções computacionais mais eficientes.

---

## Conteúdos Estudados

Ao longo da disciplina, são abordados conceitos fundamentais relacionados às estruturas de dados e aos algoritmos, incluindo:

* Estruturas de dados;
* Arrays e matrizes;
* Listas encadeadas;
* Pilhas;
* Filas;
* Recursividade;
* Árvores;
* Árvores binárias;
* Algoritmos de busca;
* Algoritmos de ordenação;
* Análise de complexidade;
* Ponteiros e alocação dinâmica;
* Implementação e manipulação de estruturas de dados.

---

## Finalidade do Repositório

Este repositório possui finalidade exclusivamente **acadêmica e educacional**.

Seu objetivo é registrar as atividades desenvolvidas durante a disciplina de **Estrutura de Dados II**, documentando meu processo de aprendizado, evolução técnica e aplicação prática dos conteúdos estudados.
