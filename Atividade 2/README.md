Estrutura de Dados II

Repositório destinado ao armazenamento de exercícios, atividades práticas, estudos e projetos desenvolvidos durante a disciplina de Estrutura de Dados II.

O objetivo deste repositório é registrar minha evolução na disciplina e aplicar, na prática, conceitos relacionados à estruturação, organização, manipulação e processamento de dados por meio de algoritmos.

Objetivos
Compreender diferentes estruturas de dados;
Desenvolver algoritmos eficientes para manipulação de dados;
Aplicar conceitos de busca e ordenação;
Analisar a complexidade de algoritmos;
Desenvolver soluções utilizando estruturas de dados;
Aprimorar a lógica de programação e resolução de problemas.
📖 Conteúdos

Durante a disciplina, serão estudados conceitos como:

🔹 Estruturas de dados;

🔹 Arrays e matrizes;

🔹 Listas encadeadas;

🔹 Pilhas;

🔹 Filas;

🔹 Recursividade;

🔹 Árvores;

🔹 Árvores binárias;

🔹 Algoritmos de busca;

🔹 Algoritmos de ordenação;

🔹 Análise de complexidade;

🔹 Ponteiros e alocação dinâmica;

🔹 Implementação de estruturas de dados.

Tecnologias

As atividades podem utilizar diferentes linguagens e ferramentas, de acordo com os requisitos de cada exercício.

Principais tecnologias:
